# 主機控制台介面整理驗證

驗證日期：2026-11-15（Asia/Taipei）。

## 本次範圍

- 網頁由八個入口收斂為「主機監控」與「觀測排程」，登入直接進入主機頁。移除舊總覽、專案、草稿、計畫、執行、結果頁面的路由與載入；原有後端功能與歷史資料保留。
- 主機名稱與位址只顯示一次。CPU／RAM／GPU 為主要資訊；磁碟、網路、硬體詳細資料預設折疊。超過四張 GPU 時使用有文字提示、可鍵盤操作的捲動區域。
- 更新字級、對比、留白與手機按鈕尺寸；以文字與綠／紅／灰共同區分讀取正常、失敗與未監控。監控中只顯示可用的停止操作，選取變更未成功套用時才提供重試。
- SSH 新增／編輯改用對話框；自動聚焦、Tab 限制於框內、Escape 關閉並返回原按鈕。儲存中不可關閉。
- 修正頁面切換的捲動位置與排程編輯請求中切換到新增頁時可能殘留的載入狀態。
- 初次資料載入顯示載入提示，避免把尚未取得的清單當成空資料。

使用 `antigravity-gemini-subagent` 取得唯讀設計建議。Gemini 僅收到介面現況的文字摘要，未提供密碼、環境檔或資料庫；最終修改與畫面驗證由 Codex 完成。
